* Make sure you read README.md first, before making any changes
* When you make any changes, you need to make sure the ci/cd tests are passing
* If you run into an error that requires to change anything in the ../be folder, you need to make those backend changes separately, make sure they pass all the backend tests, and only then work on the frontend.
* Always prioritize using mantine UI. 
* The designs should be mobile first
* Custom css is only possible only if it cannot be done using mantine.
